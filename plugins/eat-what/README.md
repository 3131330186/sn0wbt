# 吃什么 v1.0.0

安装在 `resources/app/plugins/eat-what/`。从插件页打开“吃什么”的设置弹窗即可编辑触发词、默认推荐数量和餐馆文本。

## 使用

- 默认触发词：吃什么、吃啥、午餐推荐、晚餐推荐。留空关闭关键词匹配，不恢复默认值。
- `今天吃什么？`：按北京时间读取午餐或晚餐列表，默认随机给出 3 个不重复候选。
- `晚餐吃什么？` / `中午吃啥？`：优先读取指定餐别。
- `把寿司加入午餐`、`晚餐添加烧烤`：AI 提取原消息中的名称，写入对应列表。
- `把寿司加入吃什么备选`：没有指定餐别，由工具按当前北京时间归类；16:00 前午餐，16:00 起晚餐。
- `午餐和晚餐都加入寿司`：可加入两份列表，已有名称不重复添加。
- 普通的“今天吃了寿司”不会保存。关闭“记住群友明确添加的餐馆”后，群聊不能添加。

文本保存在安装数据目录的 `eat-what/meals.txt`，正常安装版为\QQ Agent\data\eat-what\meals.txt`。所有群共用此餐馆类型列表，不记录成员隐私。每次推荐重新读取文本，不使用过期缓存。午餐与晚餐允许为空，空列表不会恢复默认内容。

弹窗显示文本的完整路径，并提供“直接打开列表”（记事本）和“打开所在文件夹”按钮。直接编辑文件保存后，重新打开弹窗即可读取最新内容。旧核心尚未重启时，刷新界面也可查看路径并使用“打开数据目录”入口。

格式示例（支持每行一个名称，也兼容逗号、顿号分隔）：

```text
[午餐]
黄焖鸡
卤肉饭

[晚餐]
火锅
烤串
```

设置弹窗读取这份真实文件，保存会校验格式并原子替换；如果群聊学习或外部编辑已更新文件，拒绝覆盖并提示重新打开。文件只在首次不存在时使用默认列表初始化。

## 人设调用

可在人设中追加：

> 群友问吃什么时，调用 `eat-what__meal_options`，action 为 recommend。未指定午餐或晚餐时 meal 为 auto，默认推荐三个候选，再自然回复。群友明确要求记住餐馆时，按插件提示使用 add。

工具 actions：`recommend` / `list` / `add`；meal：`auto` / `lunch` / `dinner` / `both`。add 需要 `items` 和本轮消息 `sourceId`，名称必须来自原消息，工具不接受任意文件路径。留空触发词后仍可通过人设、正常 @ 或其他已有唤醒方式调用工具；开启群聊学习时，明确添加餐馆的请求仍可独立唤醒。

## 核心接口扩展

本次新增通用 `message.trigger` 能力，让插件在普通档位未命中时补充关键词触发，覆盖首次入站和运行中积压消息；禁用插件或工具时不会额外唤醒。新增通用 `settings.text-document` 编辑接口，允许管理员编辑插件自身指定的文本文件，仍使用控制台现有鉴权。

这两项涉及 `src/prompt.js`、`src/orchestrator.js`、`src/routes.js`，首次安装后需重启 QQ Agent。界面编辑器在 `ui/app/06-settings-render.js`，刷新页面即可加载。软件更新可能覆盖核心补丁，备份在 `_codex_chatgpt_work/eat-what-backup-20261007/`。
